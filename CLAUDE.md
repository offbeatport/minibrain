# Minibrain

Repo rules on top of `~/Development/CLAUDE.md`.

## Plan

- `ROADMAP.md` is the technical plan. Read it before implementing; treat it as settled unless the user changes it.
- This repo is public. Business content (customers, pricing, design partners, investors, license strategy) lives in
  the private repo at `~/Development/private/minibrain_plan.md` and never lands here.

## Layout

- `minibrain/`: Python package, one folder per future service: `registry`, `data`, `ml` (train and eval job
  processes), `serve`, `gateway` (`/v1`), `api` (`/api` for the UI). `worker.py` runs jobs; `cli.py` is the entry point.
- `web/`: Vite SPA. `src/api/schema.d.ts` is generated by `pnpm gen:api`; never edit it by hand.
- `tests/`: backend tests with a fake serving backend; no model downloads.
- `spikes/`: throwaway experiments that fed the roadmap.
- `hatch_build.py`: wheel builds run `pnpm build` and package `web/dist` as `minibrain/web`; editable installs skip
  it, and `minibrain/settings.py` falls back to `web/dist`.
- `mise.toml`: developer tasks (`mise run setup | dev | check | build | api-types`).

## Code rules

- Hashing and crypto stay FIPS-ready: SHA-256 for content hashes and signatures, never MD5 or SHA-1 (ruff `S324`).
  Non-security hashes pass `usedforsecurity=False`. All crypto goes through OpenSSL or the `cryptography` library;
  never hand-rolled.
- Identity headers from a reverse proxy are trusted only when the request comes from a configured proxy address.

## Portfolio deviations

- Python backend. The frontend is a Vite SPA served by FastAPI, not TanStack Start.
- No better-auth (TypeScript-only).
- No outbound telemetry, ever: the product runs air-gapped. obp-base OpenPanel and Sentry stay off by default or point
  at self-hosted instances.
- TypeScript API client generated from FastAPI's OpenAPI schema.
- obp-ui theme: the user's own token overrides (2026-10-30) at the end of `web/src/styles.css`, light and dark. They
  set Inter, Space Grotesk and JetBrains Mono, so `styles.css` imports `obp-ui/fonts-alt.css`.
- Sidebar nav items carry icons (the kit's `NavItem` needs one, and the collapsed rail shows only icons): the
  user's choice on 2026-10-30, an exception to the portfolio's no-icon-per-nav-item rule.
